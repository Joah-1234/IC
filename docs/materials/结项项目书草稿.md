## 二、项目主要内容

### 成果简介（不少于500字）

本项目围绕人脸识别系统中的安全问题展开，聚焦于人脸反欺骗（Face Anti-Spoofing, FAS）任务，目标是研究并实现一种能够有效应对未知攻击的人脸活体检测方法。随着移动支付、门禁认证、智能安防等应用场景中人脸识别技术的广泛落地，照片翻拍、视频回放、屏幕重放乃至高仿面具等攻击手段也不断演化。传统基于监督学习的人脸反欺骗方法通常在已知攻击样本上表现较好，但在跨数据集、跨场景以及面对未知攻击类型时，往往存在明显的性能下降。因此，提升模型对未知攻击的泛化能力，成为当前人脸反欺骗研究中的关键问题。

本项目以论文《Token-Wise Asymmetric Contrastive Learning in Countering Unknown Attacks for Face Anti-Spoofing》为主要参考对象，围绕其提出的 Token-Wise Asymmetric Contrastive Learning（TACL）思想进行复现与工程实现。项目的核心思路是：不再将所有真假样本一视同仁地拉开或聚合，而是通过不对称对比学习机制，强力拉近活体样本之间的特征分布、强力推远活体与攻击样本之间的距离，同时不强行约束不同攻击样本之间的相似性。这样的设计可以避免模型把“已知攻击模式”过拟合成固定簇结构，从而增强对新型未知攻击的适应能力。

在实现层面，项目完成了从数据整理、图像预处理、模型搭建、损失函数实现、训练稳定性控制到结果导出的完整流程。数据方面，选取 OULU-NPU、CASIA-MFSD、ReplayAttack 和 MSU-MFSD 四个公开数据集，按照 Leave-One-Out 协议构建跨域训练测试划分。预处理方面，使用 MTCNN 对人脸区域进行裁剪，同时增加了基于目录规则与图像内容的双重过滤机制，对深度图、红外图、低动态范围图、全黑损坏图等非目标模态进行剔除，尽可能保证输入图像为适合 RGB 活体检测的样本。模型方面，采用 ViT 作为主干网络，结合 Token 级特征建模、全局最大池化、ArcFace 分类头与对比学习损失，构建了可运行的跨域人脸反欺骗系统。

项目还面向结项验收需要，对实验过程进行了工程化增强。代码能够自动保存训练曲线、测试指标、逐样本预测结果和特征文件，并支持自动生成 ROC 曲线、混淆矩阵、t-SNE 可视化、样本预测示例图及多协议汇总表。这些结果既可以用于模型性能分析，也可以直接作为结项报告和答辩展示中的多媒体支撑材料。总体而言，本项目已完成基于非对称对比学习的人脸反欺骗方法实现与初步验证，形成了较完整的算法复现与实验分析框架。

## 三、项目实施情况总结（1500字左右）

### 1. 项目研究创新点与学术价值

本项目的创新点主要体现在三个方面。第一，研究问题聚焦于“未知攻击”场景下的人脸反欺骗泛化问题，而不是仅追求封闭集条件下的分类精度。与常规二分类思路相比，这一研究目标更贴近真实应用场景，因为实际系统在部署后往往会遇到训练阶段未见的新型欺骗方式。第二，项目引入了不对称对比学习机制，将活体样本视为应当聚合的稳定类，将攻击样本视为无需强行聚合的开放类，从损失设计层面强化了真假样本之间的判别结构。这一思路突破了传统“所有类别均应形成清晰簇结构”的默认设定，更适合处理攻击模式高度多样化的人脸反欺骗任务。第三，项目采用 Token 级特征学习方式，使模型关注局部伪造痕迹而非整体身份语义，有助于降低对背景、个体外观和场景偏差的依赖，提高跨域条件下的稳定性。

从学术价值上看，本项目将对比学习、Transformer 局部表征与活体检测任务结合起来，完成了从理论理解到工程落地的验证过程。一方面，它为人脸识别系统中的安全子任务研究提供了可复现的实现框架；另一方面，它也为“开放世界攻击检测”这一类更广泛的视觉安全问题提供了思路。虽然当前项目仍存在算力、训练周期与预训练权重条件受限等现实约束，但从方法框架、实验组织和误差分析上看，已经具备较好的科研训练价值。

### 2. 项目执行过程与实施情况

项目实施过程大致分为五个阶段。

第一阶段是文献调研与问题澄清。项目组系统阅读了人脸反欺骗、对比学习、Vision Transformer、ArcFace 以及跨域泛化相关文献，明确本项目研究对象是“人脸识别系统中的安全子任务”，即判断输入人脸是真实活体还是攻击样本，而非身份识别本身。在此基础上，项目组进一步分析了传统 CNN 方法、传统纹理特征方法以及常规二分类深度学习方法在未知攻击场景下的局限性，确定以 TACL 作为复现对象。

第二阶段是数据集整理与预处理流程设计。由于四个公开数据集目录结构不统一，且已有数据中存在被二次处理过的痕迹，项目组没有采用简单的模糊匹配，而是改为基于目录结构和内容规则的清洗方案。具体来说，原始数据保持只读，处理结果统一输出到当前项目目录下。预处理脚本使用白名单方式限制每个数据集仅扫描合法顶层目录，并通过目录关键词过滤与像素级内容过滤剔除深度图、红外图、异常灰度图、低动态范围图和损坏图像。对 CASIA-MFSD 等层级较复杂的数据集，还针对其真实目录结构修正了标签识别逻辑，避免将受试者编号误判为样本类别。通过这一步，项目建立了更可信的 RGB 活体检测输入数据基础。

第三阶段是模型与损失函数实现。项目组基于 PyTorch 和 timm 实现了 ViT 主干网络、Token 级特征提取、全局最大池化聚合和 ArcFace 分类头，并实现了 TACL 的核心损失逻辑。在损失设计上，项目明确区分了三类关系：活体与活体之间应聚合，活体与攻击之间应分离，攻击与攻击之间则不进行过强约束。与常规对比学习相比，这一机制更符合“攻击样本具有开放性、多样性”的任务属性。为了支撑对比学习训练，数据加载部分还实现了双视图增强，即对同一输入图像生成两份独立随机增强结果，形成正样本对。

第四阶段是训练稳定性优化与实验组织。由于 Transformer 在跨域大规模数据上训练时容易出现数值不稳定，项目组采取了一系列防御性措施，包括关闭 AMP 混合精度、采用 FP32 训练、加入梯度裁剪、控制学习率规模、对加载权重进行显式检查，并在数据读取失败时直接抛出异常，避免模型静默吞入无效输入。为便于后续结项和复查，训练与测试脚本均支持自动保存配置快照、训练历史、测试预测文件与特征文件。

第五阶段是结果整理与结项材料支撑代码建设。考虑到项目后期需要提交结项报告和答辩展示，项目组在代码中额外增加了图表与统计导出功能。训练阶段可自动输出训练曲线图，测试阶段可导出 ROC 曲线、混淆矩阵、t-SNE 图、样本预测示例图以及各协议汇总结果。同时，数据整理过程还会自动生成 `live/spoof/unknown` 的统计表，为结项报告中的数据集说明和实验设置部分提供依据。

### 3. 成果应用与推广及社会效益

本项目的直接成果是形成了一套针对人脸反欺骗任务的完整工程实现与实验分析框架，具备较好的教学与科研训练价值。首先，该成果可直接服务于本科生科研训练和相关课程实践。项目涉及数据清洗、计算机视觉、深度学习、对比学习、Transformer 建模、实验统计与结果可视化等多个环节，适合作为模式识别、机器学习和计算机视觉课程中的综合型实践案例。其次，该项目成果对真实人脸识别系统的安全增强具有潜在参考意义。虽然目前仍以公开数据集实验验证为主，但其核心思想面向的是未知攻击场景，这对移动支付、刷脸门禁、远程身份认证等应用环境具有现实意义。第三，本项目在实现过程中沉淀出的数据清洗与结果分析流程，也可推广到其他生物识别安全任务，例如指纹活体检测、虹膜反欺骗与跨域视觉安全检测等方向。

从社会效益角度看，随着人脸识别技术在校园、企业和社会治理场景中的广泛落地，欺骗攻击的风险也不断增加。提升系统对未知攻击的鲁棒性，有助于增强身份认证系统的安全性和可信度。虽然本项目尚处于科研训练和复现验证阶段，尚未形成直接产业化成果，但其研究思路和工程实现对智能安防与身份认证领域具有一定的启发和支撑作用。

### 4. 研究存在的不足或欠缺，尚需深入研究的问题等

本项目目前仍存在若干不足。首先，项目在训练条件上受到算力资源和时间周期限制，尚未完成大规模充分训练，部分协议下的结果仍需要更长周期的超参数调整与反复验证。其次，项目当前未获得与论文条件完全一致的预训练权重，这将导致模型从随机初始化开始训练或仅能采用替代初始化方案，从而影响最终性能，并使结果与论文原始数值存在差距。第三，部分数据集在公开流传过程中已经过二次处理，目录结构与官方原始分发形式并不完全一致，虽然项目已尽可能通过白名单扫描、路径过滤和内容过滤降低噪声，但仍存在一定的数据源偏差风险。第四，在评测协议上，当前 HTER 的实现采用测试集 EER 阈值进行近似计算，与部分论文使用开发集阈值的标准定义并不完全一致，因此结果在报告中需要明确说明为近似实现。

后续若继续深入研究，可从以下方向展开：一是引入更稳定的公开 ViT 预训练权重，提升训练初始条件；二是在更多跨库协议上系统开展对照与消融实验，验证 TACL 各模块的独立贡献；三是尝试更轻量化的 Transformer 主干，以降低计算复杂度；四是进一步细化错误分析，特别是针对易误判攻击样本的局部可解释性研究。总体来看，本项目已经完成了较扎实的阶段性研究工作，但在追求更高复现精度与更全面实验结论方面，仍有进一步深化空间。
