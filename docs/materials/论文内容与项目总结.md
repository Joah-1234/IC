# 论文内容与项目总结

## 一、论文内容重述

### 1. 研究背景

本项目所复现与实现的核心论文为《Token-Wise Asymmetric Contrastive Learning in Countering Unknown Attacks for Face Anti-Spoofing》。论文聚焦于人脸识别系统中的安全问题，具体任务不是身份识别本身，而是人脸反欺骗，即判断输入人脸图像究竟是真实活体，还是由照片、视频、屏幕回放等方式构造的攻击样本。在现实场景中，人脸反欺骗模型往往面临“跨域泛化”困难：训练数据来自有限的数据集和攻击类型，而测试时遇到的相机设备、成像条件、背景环境、攻击介质与训练阶段并不一致，甚至可能出现训练中从未见过的新型攻击方式。传统监督分类方法通常会过度依赖已知攻击特征，导致在未知攻击或未知域上性能显著下降。

该论文提出的核心思想，是利用 Vision Transformer 的 token 表征能力，把图像划分为多个局部 patch token，并在 token 级别上引入非对称对比学习机制。论文认为，真实活体样本在不同域间尽管存在成像差异，但其本质上属于同一类语义，应在特征空间中尽量聚合；而伪造样本由于攻击方式复杂、外观差异大，不应被强行压缩到同一紧凑簇中，只需要保证其与真实样本保持足够距离即可。因此，论文中的非对称对比学习并不是简单地把所有同类样本拉近，而是采用“live-live 拉近、live-spoof 拉远、spoof-spoof 不强制聚合”的策略，以提升模型在未知攻击场景下的鲁棒性和泛化能力。

### 2. 论文方法概述

论文方法的整体结构可以概括为三个层面。首先，在骨干网络层面，使用 Vision Transformer 提取图像的 patch token 特征，使模型能够感知局部纹理、边缘反射、显示伪影等细粒度攻击痕迹；其次，在监督学习层面，引入基于角度间隔的分类约束，对真假脸建立更清晰的判别边界；最后，在特征学习层面，通过 Token-Wise Asymmetric Contrastive Learning 对活体和攻击样本的特征分布进行结构化约束，使模型既能保持真假分离，又能避免对未知 spoof 形成过于僵硬的类内收缩。

论文的实验通常在 OULU-NPU、CASIA-MFSD、ReplayAttack 和 MSU-MFSD 四个公开数据集上开展，使用 Leave-One-Domain-Out 的跨域协议进行评估，例如 `ICM_to_O` 表示在 ReplayAttack、CASIA-MFSD 和 MSU-MFSD 上训练，在 OULU-NPU 上测试。评估指标主要包括 AUC、EER、HTER 等。论文希望通过实验说明：在面对未知攻击与目标域迁移时，非对称对比学习相比单纯分类方法，能够获得更强的泛化表现。

## 二、我们项目实际完成了什么

### 1. 数据工程与预处理实现

本项目首先围绕四个公开数据集建立了统一的数据处理链路。考虑到原始数据集中包含被他人二次整理过的目录、不同命名规则、深度图与红外图混入、部分异常图像以及全帧数据量过大等问题，我们没有直接将原始数据用于训练，而是从工程角度重新构建了数据清洗流程。具体而言，项目实现了基于目录白名单的预筛选、针对深度/红外/异常图像的规则过滤、MTCNN 人脸区域裁剪、人脸图像统一输出，以及最终的 `live/spoof` 二分类安全整理。整个流程确保原始数据目录不被修改，所有中间结果和最终训练数据都保存在项目目录下，便于重复实验和结项留档。

在数据整理过程中，我们针对不同数据集编写了单独的标签解析逻辑。例如，OULU-NPU 按父目录中的攻击类型编码判断真假，ReplayAttack 与 MSU-MFSD 主要依据 `attack/real` 目录进行归类，CASIA-MFSD 则需要根据其更复杂的子目录结构判断真假样本。后续又根据人工核查结果，修正了 CASIA-MFSD 中 `HR_1` 为真脸、其余 `HR_*` 为假脸的规则，提升了训练标签的准确性。这一部分工作对实验结果影响很大，也是本项目能够逐步逼近论文效果的重要基础。

### 2. 模型与训练流程实现

项目基于 ViT-Base-Patch16-224 完成了 TACL 模型的实现，使用 token 输出作为对比学习的基础特征，并通过全局最大池化形成分类特征。分类分支采用 ArcFace 形式的角度间隔分类头，用于强化真假脸在特征空间中的判别边界；对比学习分支则实现了 Token-Wise Asymmetric Contrastive Loss，在 token 级别塑造活体与攻击样本的非对称分布结构。

在训练实现上，项目完成了双视图增强、梯度裁剪、学习率余弦退火、checkpoint 自动保存、训练配置快照记录、训练曲线自动生成等工程功能。针对复现过程中出现的效率和稳定性问题，我们又逐步加入了预训练权重加载报告、spoof 样本比例裁剪、训练增强强度调节等优化措施。特别是在后期版本中，项目成功接入了 ViT 的预训练权重，使骨干网络能够从更稳定的特征初始化出发；同时，将训练集中 spoof 数量控制在适当范围内，避免 spoof 数量过多压制 live 特征聚合。

### 3. 测试与可视化实现

项目不仅实现了训练和测试主流程，还围绕论文与结项需求补充了丰富的结果输出脚本。测试阶段能够自动计算 AUC、EER、HTER，保存逐样本预测结果与特征文件；报告生成阶段能够输出 ROC 曲线、混淆矩阵、训练曲线、样本预测图以及目标域和协议级 t-SNE 图；进一步又新增了逐轮 t-SNE 生成脚本，可观察训练过程中各类样本特征分布的演化趋势。最后，针对论文写作，还实现了论文表格和图片的自动导出脚本，能够将实验数据集统计表、对比实验表、消融实验表和论文用 t-SNE 图输出为 PNG、CSV、TEX 等格式，便于直接插入论文与结项材料。

## 三、当前最终版实验结果

在多轮调试、数据修正和训练优化后，项目当前最终采用 `ICM_to_O` 协议作为主展示结果，即使用 ReplayAttack、CASIA-MFSD 和 MSU-MFSD 作为训练源域，在 OULU-NPU 上进行测试。该版本在接入预训练 ViT 权重、修正 CASIA 标签规则、调整 spoof 比例以及减弱训练增强后，获得了如下测试结果：

- AUC：97.13%
- EER：8.40%
- HTER：8.40%

这一结果已经明显优于项目前期的初始复现结果，说明经过数据与训练策略调整后，模型在跨域人脸反欺骗任务上具备了较好的泛化能力。与此同时，我们也注意到，虽然特征可视化图中 `live` 尚未完全聚成论文中那种极其理想的单簇结构，但 `live` 与 `spoof` 在整体上已经形成了较清晰的可分区域，测试域样本也能够大体落入正确的判别区域。因此，当前版本可以合理地作为项目的最终主结果，用于论文和结项展示。

## 四、结果分析与当前不足

从项目整体过程看，当前结果的提升主要来自四个方面：一是接入了 ViT 预训练权重，显著改善了骨干网络的初始化质量；二是修正了数据集中的关键标签规则，减少了训练标签污染；三是适度控制 spoof 样本比例，减轻了严重类别失衡对对比学习结构的干扰；四是将训练增强从过强设置调整为更适合活体检测的温和版本，更好地保留了颜色纹理与攻击细节信息。

但项目仍存在一定不足。首先，当前的 HTER 是在测试集 EER 阈值上计算的近似值，与部分论文使用开发集阈值的标准评测口径存在差异；其次，特征可视化虽然已经具备明显的真假分离趋势，但 `live` 的紧致聚合程度仍未完全达到论文中最理想的示意效果；再次，消融实验尚未全部按最终最优设置完整补齐，因此论文中的消融表仍需要进一步结合真实实验结果完善。尽管如此，从项目复现完整度、工程实现程度和当前最终指标来看，本项目已经形成了较为完整的研究闭环。

## 五、项目的主要内容

本项目的主要内容是围绕“非对称对比学习在人脸反欺骗中的应用”开展方法复现、工程实现和实验验证工作。项目以跨域人脸反欺骗为核心任务，针对传统方法在未知攻击场景下泛化能力不足的问题，研究并实现了基于 Vision Transformer 和 Token-Wise Asymmetric Contrastive Learning 的人脸活体检测模型。围绕这一目标，项目主要完成了以下内容：第一，系统梳理并整理了 OULU-NPU、CASIA-MFSD、ReplayAttack 和 MSU-MFSD 四个公开数据集，建立统一的数据清洗、裁剪和标签整理流程；第二，实现了基于 ViT 的 token 级特征提取网络，并在其上构建 ArcFace 分类头与非对称对比损失函数，完成模型主体搭建；第三，设计并实现了适用于对比学习的双视图数据增强方式，以及包含 checkpoint 保存、训练曲线记录、测试指标导出和图表自动生成在内的完整训练测试框架；第四，在标准跨域协议下完成实验，分析了不同配置下模型在未知域上的表现，并通过 ROC、混淆矩阵、t-SNE 等方式对实验结果进行了可视化解释；第五，根据复现过程中暴露出的标签规则、类别失衡、预训练初始化和增强强度问题，持续迭代优化实验配置，使项目最终获得了一版较优的跨域泛化结果。整体上，本项目不仅完成了论文方法的程序复现，也形成了一套可复用、可扩展的人脸反欺骗实验工程框架。

## 六、项目实施情况总结

本项目实施过程总体经历了“方案确定、数据处理、模型实现、实验验证、问题修正、结果固化”六个阶段。前期阶段主要围绕论文研读和技术路线分析展开，明确了本项目并非做人脸身份识别，而是研究人脸识别系统中的安全子任务，即人脸反欺骗。中期阶段，重点完成了四个公开数据集的收集、筛选和统一整理，解决了原始目录结构不一致、深度图和红外图混入、样本标签规则复杂等问题，并搭建了 MTCNN 预处理、`live/spoof` 整理和训练测试主框架。进入模型复现阶段后，项目实现了基于 ViT 的 token 级特征提取结构、ArcFace 分类头和非对称对比损失函数，完成了训练脚本、测试脚本、图表输出脚本以及论文材料生成脚本的开发。随后，在实验推进过程中，项目不断针对指标不理想的问题进行定位和修正，例如补充预训练权重加载、调整 spoof 样本比例、减弱数据增强强度、修正 CASIA-MFSD 标签解析逻辑，并通过逐轮 t-SNE 分析脚本观察模型特征演化过程。经过多轮迭代，最终在 `ICM_to_O` 协议下获得了较高的 AUC 和较低的 HTER，初步达到了项目预期目标。总体而言，本项目已较好地完成了从理论理解到工程实现再到实验分析的全过程，具备了较清晰的研究价值与应用意义，同时也为后续进一步补充多协议实验、严格消融分析和评测口径完善打下了基础。
